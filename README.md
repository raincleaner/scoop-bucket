# Rain Cleaner Scoop bucket

Unofficial-style bucket maintained by the Rain Cleaner team.

    scoop bucket add raincleaner https://github.com/raincleaner/scoop-bucket
    scoop install raincleaner

Rain Cleaner is a Windows 10/11 (64-bit) cleanup tool. The free version has no ads and no time limit; Pro is optional.
The Windows builds are not code-signed yet, so Windows may show an unknown-publisher warning. Hashes are published at https://raincleaner.eu/trust and are checked by Scoop on install.
